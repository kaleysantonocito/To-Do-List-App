# To-Do-List-App

An interactive to do list application designed to help users organize their tasks, manage priorities, and stay focused using a built in countdown times.

## Features

- **Task Management:** Add, edit, delete, complete, and restore tasks.
- **Task Prioritization:** Assign tasks a high, medium, or low importance level. Active tasks are automatically organized by priority.
- **Doing Now:** Select one active task to focus on at a time.
- **Focus Time:** Set a countdown timer between 10 and 120 minutes in 10 minute time increments.
- **Task Completion:** When the timer finishes, choose whether to mark the selected task as complete or continue working on it.
- **Responsive Design:** A clean, user friendly interface designed for different screen sizes.
